# Agent Forge – Deepdive Day 2

### Event Objectives

- Deep-dive into Amazon Bedrock AgentCore at an advanced level (L300), focusing on 3 core areas: Memory, Evaluations, Observability
- Cover the full set of AgentCore components: Registry, Harness, Tools, Payments, Optimization, Policy
- Pair theory with a hands-on lab so attendees can practice directly during the session
- Connect with the community building agentic AI on AWS

### Session Content

- **AgentCore L300**: a deep look at 3 core modules — Memory (letting an agent retain context/interaction history across sessions), Evaluations (systematically measuring agent response quality), Observability (real-time monitoring and debugging of agent behavior)
- **AgentCore Components**: an overview of the platform's 6 main components — Registry (agent registration/management), Harness (the agent runtime framework), Tools (tool-calling integration), Payments (handling transactions within an agent), Optimization (performance/cost tuning), Policy (managing permissions and behavior constraints for agents)

### Hands-on Lab

- Add memory for more personalized agent responses per user
- Explore Agent Observability to monitor agent behavior
- Use AgentCore Evaluations to measure agent performance
- Explore AgentCore Harness

### Expected Application to My Project

- Consider applying AgentCore's Memory mechanism to the project's RAG chatbot, so the agent retains conversational context across multiple turns instead of treating each question independently.
- Look into AgentCore Evaluations as a more systematic way to measure answer quality, instead of relying only on manual testing as I do now.
- Interested in Observability for clearer debugging when Co-RAG or Self-RAG produces unexpected results.
